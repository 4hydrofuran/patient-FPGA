# C04 电脑工程候选：质量与外发许可待验收

2026-10-02 按用户要求提前推进 C04。用户已确认此前识别问题是设备麦克风问题；这是用户反馈，不代替设备修复后的真人质量重测。本轮不自动录音。

当前冻结候选：Zipformer-small-CTC 中文 INT8 ASR + Matcha 中文 Baker / Vocos TTS。推理线程 2，TTS 句批次 1，速度、暂停比例均 1.0；流式块 200 ms，端点 1.2 秒仅提示，显式 finish 唯一提交。配置和模型/数据摘要在 evidence/c04/freeze.json，未根据最终集调参。

候选 zip 会包含源码、worker/selftest、受控安装、固定 Windows / aarch64 离线依赖、来源/模型摘要、公开开发烟测音频与署名、工程证据、一页摘要和逐文件 SHA256。没有私人麦克风录音、手工测试转录、C02 合成盲听音频、虚拟环境或未确认许可的模型资源；模型资源需另行获准并在本地核对安装。

独立复现先静态检查，再解压到新目录、安装到不同的新 runtime 目录；测试日志写另一个新目录，原包不被安装/自测修改。真实 ASR/TTS 自测需要获准的模型资源；未安装模型时只可通过契约/工程检查，--real 不能伪报通过。验证本机包时会在同一电脑的私有 runtime 复制既有 hash 一致的模型，仅用于本地实测，不加回 zip。

新增可选 --diagnostic-log NEW_DIRECTORY，日志仅含请求编号、操作、类型、事件、错误码与 epoch 等元数据；不记转录正文、文字输入或音频路径。轮转默认单文件 64 KiB、3 份备份。只接受新目录，避免把用户原有日志当作自有文件轮转删除。reset/shutdown 仍只删除 worker 自己生成的音频，调用方输入与其他会话文件保留。

受限网络测量区分：Python audit guard + 当前执行环境网络限制、新 worker 模型冷启动，与物理断网/电脑重启不同。保留 network_probe、每次进程 hello-ready、完整 trace、stderr、失败/超时、reset 和清理结果；不把程序未调用网络当作已经拔网线。物理断网、OS 重启条件仍需独立现场执行。

30 次冷启动循环与 200 次模块循环只使用既有公开/自编开发数据。200 次包含 whole-WAV ASR、逐块 ASR、TTS 与 reset，不是 A 的完整问诊/LLM/扬声器端到端 200 轮。无实际出声、最终 CER、人工否定/数字语义、2 小时稳定性或板测结论。

ARM64 材料固定 CPython 3.12、GNU/Linux、glibc >=2.27；校验发布者 hash 与 ELF AARCH64 文件头，不宣称已 cross-build 或兼容 A53 全部指令。真实 rootfs/ABI、CPU features、原生 import、Linux 麦克风与板端性能待确认。说明见 deploy/aarch64/README.md。

独立真人 ASR 最终录音为 0，C02 14 条盲听未填；C01 小样本严格 CER 24.422% 不能代替授权普通话 CER≤15% 验收。ASR/Matcha/Vocos 导出分发许可待确认，Baker 训练数据存在非商业限制。当前仅本地工程草稿，不发布给 A、不替换默认、不预约板卡。
