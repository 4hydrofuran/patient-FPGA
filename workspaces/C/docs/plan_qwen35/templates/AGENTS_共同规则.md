# 项目规则片段：先与现有AGENTS合并，不覆盖
1. 板端固定Qwen3.5-0.8B，文本模式、非思考；开发助手按各自固定选项，不按任务切换。
2. 开始任务仅先读取本角色状态、固定公共接口、当前阶段与最近失败日志；不递归扫描他人开发目录。
3. 默认模块可运行，候选模块只在约定验收阶段选择。未收到候选不是本角色无板开发的阻断。
4. 先完成必需的无板工作再进实板；工具构建、电脑速度、模拟接口都不能写成真实板测。
5. 保留原项目/权重/历史证据；旧0.5B数据不充当新0.8B测试数据。
6. 不全局升级依赖，不使用开发机-march=native交叉构建A53，安装失败先定位而非换整个平台。
7. 不伪造模板/硬件回退、计数、医学审核、波形、功耗或论文录用；未测填null/NOT_TESTED。
8. 上板先确认设备、备份与恢复；破坏性刷写、采购、登录和授权须用户明确决定。
9. 每阶段保存文件、命令、版本、通过/失败域与下一步。失败测试保留，不通过删例或放宽门槛宣告成功。
10. 不擅自修改公共契约；软件候选按固定接口成套发布，内部库/位流不可跨版本拼接。
11. 不向聊天或仓库输出令牌、密码、私钥和许可证正文；真实语音须授权，默认不长期留存。
12. A维护系统实现，B维护计算候选，C维护语音候选；B/C不要求改动对方目录。
