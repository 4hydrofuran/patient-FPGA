# KV260 Qwen3.5 项目基线备份（2026-10-31）

这是对当前 A 路线源代码、配置、计算 IP 交付、无语音问诊版本和语音统一 PL 候选的独立备份。备份来自已有工作区和已封存候选，不修改原工作区或默认分支；实际包含的每个文件、原始字节数及 SHA-256 见 [MANIFEST.json](MANIFEST.json)。

## 恢复

克隆本备份分支并保留全部 `kv260-backup.zip.partNNN` 与 `kv260-board.zip.partNNN` 文件，在安装了 Python 3 的电脑上运行：

```powershell
python restore.py --destination "C:\KV260-restore"
```

目标目录必须不存在或为空。脚本先验证分片及重组 ZIP 的 SHA-256，再逐文件恢复并核对清单；板端启动固件与永久网口配置恢复在 `board-snapshot/`，对应 [BOARD_MANIFEST.json](BOARD_MANIFEST.json)。脚本不会覆盖已有文件。恢复后如需在板端执行，应按相应交付清单检查 Linux 文件权限、环境与依赖。

备份包括 2026-10-30 最新文字问诊候选、2026-10-28 v10 统一 PL/音频候选、被动停驻候选、无语音回退资产、相关源代码与计算核交付。公开版不包含模型权重、认证凭据或真实用户问诊记录；用户记录另存于受限的本机备份。它不是 SD 卡镜像或完整工作站镜像，模型资产需使用原有位置。

2026-10-31 板卡经串口核对为原 KV260，默认 PL 已加载，当前运行 `6.8.0-1036-xilinx`；网口配置保留 `192.168.137.2/24` 并增加永久地址 `192.168.2.2/24`。语音候选的正常录放、与模型并发及完整恢复仍未通过板端验收，不能把归档当成部署成功的证据。
