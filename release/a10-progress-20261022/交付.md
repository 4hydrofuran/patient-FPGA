1. 实板身份、串口/SSH、原 Ubuntu 24.04.2 ARM64/内核 6.8.0-1015-xilinx、DT、XRT、CMA/温度等采集，以及 ARM64 链接短检查。原始 profile 与后续增量都保留；不同启动记录不能混为同一窗口。
2. 受控空载配置和恢复工具、短 vector-add 主机程序、小 BO/双账与日志门禁、取消/超时安全逻辑及电脑测试。工具准备不代表真实计算已通过。
3. IRQ 引用/释放问题定位，irq1 空载卸载实际 double-free/Oops 最小复现；新修复补丁、生命周期 ASan/UBSan 对照、ARM64 编译以及 irq2 完整电脑内核/模块/FIT 打包审计。所有原失败保留。
4. 原启动文件与模块备份核验，irq2 新文件并存暂存和回读通过；6218 个模块哈希与电脑清单一致，原默认文件未改变。暂存最高记录温度约32.2°C，不是实时温度或计算性能。
5. irq2 专属试启动入口及48项电脑安全检查；已获一次试启动授权，但启动前因旧活动租约被门禁拦截，**实际重启0、irq2启动0、真实计算0**。

## 包含与不包含

包含 A10 源码/测试、必要 A1 辅助源码、内核修复派生源码/补丁/审计、板端文本证据、公共契约和状态文档。`MANIFEST.json` 对每个文件记录原件 SHA256、发布副本 SHA256 与是否脱敏；历史源文件不改写。失败、退出码和未测项不删改为成功。

这是工程与证据包，**不是可独立刷机或启动的镜像包**。不包含许可证、密码/私钥、系统盘/WSL/SD/QSPI 镜像、原系统备份、模型权重、完整第三方内核源树/SDK、大型候选 FIT/模块归档及二进制构建缓存。大候选保留本地，包内提供生成入口、来源/哈希和审计；实际复建需原有工具链/本地输入。截图和原始二进制串口捕获未公开，文本/JSON记录保留。完整范围见 `EXCLUDED.json`。

证据副本中的令牌/密码等字段按发布规则脱敏，原始记录留在本机；因此不能把发布副本哈希当成原始板端文件哈希。`PACKAGE_CHECK.json` 证明压缩包回读/逐项哈希与模式扫描，不证明 A10 通过。解压和查看文件不会自动连接板子。
