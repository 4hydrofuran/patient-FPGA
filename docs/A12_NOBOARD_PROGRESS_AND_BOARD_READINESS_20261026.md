# A12 优化进度与现在能否上板（2026-10-26）

## 当前结论

**安全检查优化、短提示词和私有协议链已有可复核的无板成果；常驻应用入口还没完成。现在不能直接开始新的 PL 计算板测。**

最近一次已记录的板端只读后检中，系统已恢复响应、默认平台正常、未见加速器占用，但旧启动租约仍未归档，`safe_release=false`；内核为 `6.8.0-1036-xilinx`，与当前 A12 候选要求的 `6.8.12-a10irq2` 不匹配。本报告没有连接板卡，不能把 10 月 25 日的快照当作此刻现场。

本报告聚焦本轮 A12 安全检查、前缀与应答时延优化。A10/A11及早期A12的受限实板成果保留，不能用它们替代新候选验收。来源、范围和 SHA 见[核验摘要](status/A12_NOBOARD_PROGRESS_20261026.sources.json)。

这些计时包含内容检查、END、回执和最终新鲜检查，**不包含实时应用路由、会话建立及初始权重加载/warm**；不是重复同输入的稳定分布、p95或板端预测。最新pilot04约25.3秒是整个启动/分词/warm/关闭试验耗时，不能称作应答耗时。

因此，目前不能承诺“最终板端输入后约1秒回答”或“TTFT≤10秒”。实际用户输入到可交付答案的完整计时，还要等常驻应用入口接好；真实A53/PL时延与CMA余量则须另行实测。

2. **九请求控制的完整验收**：第4～9请求、请求数/5000总预算/日志容量的提前拒绝、取消、期限、健康及持久化故障全路径。一次warm后关闭通过，不替代这些测试。
3. **新常驻候选的typed Board适配与独立装配**：匹配A53制品、原Owner/双锁/启动资产/BO/IRQ门禁、恢复与最终finish接口；CPU数值参考不能未经分析变成Board容差规则。
4. **板端恢复与安全释放收口**：旧启动租约处理、新鲜独立后检、内核/XRT/驱动/平台匹配、原告警与故障记录保留。目前没有新的放行结论。
5. **新的普通PL资源与性能基线**：无重型诊断的R0/warm/hit、真实CMA/内存轨迹、内容/EOS、正常关闭和独立释放。随后才比较同工作量严格/微批等候选。
6. **最终验收**：适用的完整数值、生命周期/故障、持续资源稳定性、输入到完整回答时延、TT10/A12第11步及医学/教师审核。调试轮数不能代替验收。

## 有没有现在就可以进行的上板工作

**可以单独安排恢复／准入的只读复核；现在不能直接开计算窗口。** 这不是要求等所有无板代码都完成才核查板卡，而是不能绕过当前现场与版本门槛。

| 工作 | 当前判断 |
| --- | --- |
| 设备身份、当前boot/kernel、默认平台、驱动/XRT、完整FD/VMA占用、锁/租约、内核日志和资源余量的只读复核 | 可作为下一项独立板端工作；须先确认可用通道和独占/授权边界。本报告未执行，也不附带写入/恢复/计算权限 |
| 原字节、不覆盖地归档旧启动死租约，再独立后检 | 需要专项授权与新鲜确认旧boot/PID、实际互斥及当前占用；不能直接删租约或沿用旧释放回执 |
| 恢复/选择匹配内核、重启或RAM引导、加载/卸载驱动/PL/DT | 不是只读检查，需准确方案及单独授权；本报告没有执行 |
| 普通R0/warm/hit资源探测 | 当前不能直接执行；下列准入条件满足后即可单独安排，**不用等待常驻服务全部完成** |
| 新短提示词、微批和常驻候选上板 | 后于原普通基线，逐候选独立绑定/数值/生命周期与性能验收；不能自行替换基线 |

普通资源探测的必需前提：

1. 当前故障已处置，旧启动租约/告警保留并正确收口，取得**新鲜独立安全释放**结论。
2. 精确设备、内核/XRT/驱动/PL及制品SHA匹配；原健康、完整占用和资源准入通过。
3. 新窗口绑定、唯一租约、原双锁及**新的计算授权**齐备；不能直接删除UNBOUND拒绝或重用旧窗口。
4. 首轮使用[已经发布的原普通资源包](../evidence/model_pl_A/20261025-resource-probe-v1/bundle-v2.zip)，不夹带新长诊断、短提示词或微批候选。

原门槛不变：CmaFree≥98304KiB、MemAvailable≥1114112KiB，前缀准备保留额外192MiB规划余量；72权重、148个显式BO、140591104字节、8192对齐、低2GiB范围和5000次总上限保持。未知在途状态不自动释放、重试或重放。
