# 唯一优化主线

当前分支 b/qwen35-compute，从已验证 B3 32-lane 实现继承。B00 不修改 HLS 数据通路。

1. B01：先锁定新形状正确性和公共输入校验，再产生新模型证据。
2. B02：量化解包/整数计算/逐lane FP32恢复、128-bit burst、AXI连接、激活重复搬运逐项测量；保留基线和独立标签。
3. B03：以 tile 为单位复用 T1..8 权重，比较 T1 与 T8；再尝试有界双缓冲和搬运/计算重叠，测背压和尾块。
4. B04：权重 BO 驻留、输入输出 BO 复用、同步和调用开销；把量化/同步成本计入最终服务边界。
5. 全权重预检查是已知成本；保持错误不写Y，不未经确认删检查。64-lane、非线性融合、注意力/LM head 扩展不作为本轮主线。

HLS II/Fmax 是综合估计；Cosim 周期不是板测；请求字节不是总线实测。按相同输入、数学、版本比较并保留负结果。
