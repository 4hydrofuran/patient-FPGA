# 已验收PS接入模板

这些文件于2026-10-27从实板web-modes-20261027-v2读回，配合CPU/FPGA切换验收通过。它们是现有PS运行窗口的接入层，保留PS owner的硬件许可、健康检查、加载及收尾流程。

此目录不包含PS bundle、模型权重、编译产物、驱动或硬件镜像；不能作为全新板卡的独立模型安装包。`run_modes.py`使用板上已安装的完整模板目录。这份副本供后端负责人核对和合并接入层改动。

`web-config.json`默认不自动打开板端浏览器，也不运行额外的连续验证脚本。模型就绪后在板上手动打开127.0.0.1:8000即可。桌面快捷方式是另一项本机预备工作，没有在本轮上板安装。
