# 无板接收门槛

| 域 | 队友本轮要求 | A后续接收 |
|---|---|---|
| 包完整性 | 原包manifest通过；候选标明原包hash、文件差异 | 独立重验hash及补丁范围 |
| 节点分类 | 新目标测试和schema；unknown明确；融合/父子不双计 | 接入实际模型图，核对命名/权重身份 |
| 投影数值 | 同ISA原hook/候选/单token primitive逐位一致 | 同ARM旧S1/新S1，及新S1/新S2 |
| 内存/生命周期 | layout/stride、哨兵、多消费者、重建释放 | 模型实际分配、内存峰值及取消 |
| 性能 | 只报PC，采集原始重复样本与观察开销 | 同板普通/剖面、短/自然/长输入 |
| 交叉构建 | 可选；固定SDK/A53，无运行证据就NOT_TESTED | 核对实际装载库和配置 |
| 完整模型 | 非本包独立验收要求；未运行明确NOT_TESTED | 真实logits/混合状态、原失败回归 |
| BOARD/恢复 | NOT_TESTED，不能启动设备操作 | 唯一租约、实际消费、正常释放恢复及独立后验 |

新正确性测试不能靠与原实现共享同一个新辅助函数来相互印证。至少保留冻结原hook和既有单token原语两个参照。组件相同比较不构成独立量化数学证明。

不接受：删除原失败、只报token相同而无数值检查、只用平均值没有原始样本、将x86提速换算成A53秒数、用分类变化冒充性能下降、修改公共契约或PL核、关闭安全检查、默认启用FPGA。

没有达到性能目标可以交回拒绝候选及有价值的测量，不伪造PASS。所有新增BOARD、硬件周期、功耗和板端性能字段保持null/NOT_TESTED。
