# KV260 实板功耗与输出吞吐记录（2026-11-01）

数据来自 2026 年 11 月 1 日（Asia/Shanghai）的短样本板测，板卡自身时钟不可靠。测量使用 INA260 `ina260_u14` 的 SOM 主 5 V 供电轨；这是 SOM 轨道功率，不包括整机所有供电和外设。

| 场景或指标 | 结果 | 口径 |
| --- | --- | --- |
| 服务待机功率 | 平均 3.62 W，范围 3.42–3.82 W | 5 次采样，模型已加载 |
| 模型回答时功率 | 平均 3.923 W，采样最大 4.71 W | 43 次采样，目标间隔 0.25 s |
| 端到端输出吞吐 | 0.854 token/s | 9 个输出 token / 接受至发布 10.535 s，不含 EOS |
| 串行解码速率 | 0.965 token/s | 较早的一条回答中 7 次解码 / 7.258 s，包含运行时开销 |

本次功耗样本对应一次真实模型请求，记录为 `FPGA_REAL`，未使用答案缓存；该次启用了候选生成与目标模型验证并命中前缀缓存。因此端到端数字不等同于普通逐 token 解码吞吐。采样最大值只代表本次读取的最大值，单请求也不能代表长期平均。

`POWER_THROUGHPUT_SUMMARY.json` 是原测量汇总；`SENSOR_SAMPLES.json` 保存从原始日志提取的全部功率采样和原日志 SHA-256；`SERIAL_DECODE_ANALYSIS.json` 是串行解码来源记录的原件。原始日志包含其他会话数据，保留于本地 `evidence/frontend_board_A/20261101-standalone-launch-v1/`，串行来源位于 `evidence/model_pl_A/20261101-latency-tail-readonly-v1/`。
