# 板子拿回来后：由你验收，不让刷机人员跑压力测试

## 时间和连接

预计人工操作 **约5分钟**，启动慢时最多约10分钟；一次自动采集通常几十秒以内，CPU部分只有单线程4MiB一次写读和4项整数点积，子进程限时3秒。不是全内存检查，也不是性能测试。时间不是硬件健康保证；卡住就停，不反复重试。

1. 板子断电时接好microSD、散热和数据串口；网线优先接与电脑同一个路由器。按板卡规格接可靠电源。正常上电，不按FWUEN/RESET。
2. 从串口或路由器取得板子IP；核对专业人士交付的板号、账号和SSH主机指纹。只看到风扇转不算验收；风扇策略也不能单独判断启动失败。
3. 把IP、用户名、新板标签告诉助手，我们用本包连接。你输入密码；不要发给助手，也不保存到日志。

## 现成程序怎么用

解压本包到Windows目录。PowerShell中运行（替换IP、用户名、板号）：

```powershell
./run_check.ps1 -BoardHost 192.168.1.123 -BoardUser YOUR_USER -BoardLabel NEW_KV260_01 -Cpu
```

若Windows阻止脚本，先请助手检查，不必修改系统级执行策略。没有 `-Cpu` 时只采集基础信息；`-Cpu` 仍需输入YES确认实际KV260、供电/散热正常且没有其他测试，温度无法读取、温度≥60℃或可用内存不足256MiB时会跳过计算。60℃是本次保守停止值，不是AMD损坏温度。

首次SSH核对指纹后由你确认。脚本只向该IP上传小程序，运行并下载报告，不扫描网络、不存密码、不重启、不刷写、不加载位流、不申请BO。远程目录和本地 `results-*` 均唯一，不覆盖历史结果。不因失败自动重试。

程序依赖板上Python3标准库；CPU文件已用2026.1 SDK面向Cortex-A53交叉编译，动态链接镜像的libc。不能加载时如实失败，不自动安装依赖或换CPU后端。

手动板端入口（需要先传入包文件）：

```sh
python3 quick_check.py --output report-new-01 --board-label NEW_KV260_01 --confirm-kv260 --cpu
```

## 这次看什么

| 检查 | 判定与范围 |
|---|---|
| 冷启动、串口/SSH | 能进入正确板子的Linux、稳定登录；需要人工核对板号和启动日志 |
| 系统配套 | 记录实际内核、DT、CPU、zocl、XRT版本文件、设备节点、CMA/MemTotal/可用内存、温度；权限不足/缺件明确记录 |
| ARM64最小计算 | 真实执行小程序，4MiB一次写读与整数结果一致；仅证明该小样，不证明全部DDR/模型 |
| 日志 | 留下原始输出、退出码和失败；由助手检查内核错误、版本偏差和缺项 |
| 一次正常再启动（可选，约1—2分钟） | 首轮无异常后，可手动正常关机，确认关机后再上电一次，确认还能登录；不按恢复键，不做循环重启 |

脚本输出 `COLLECTED_REVIEW_REQUIRED` 只表示收到了数据，**不是“整板/项目全部通过”**。权限不足时不要直接把整包用root重复跑；先让助手指出具体需补的只读项。

## 用户项目真正可用还差哪一步

**本包不会假装验证了FPGA计算和完整Qwen/语音应用。** 这两项仍标 `NOT_TESTED`。原因是新板实际DT/XRT未知，旧vadd主机固定1000次且超时隔离未收口；不能把它削减循环后盲目执行。

拿到报告后，先完成平台匹配及安全超时处理，再准备单独的短功能验收：FPGA小尺寸少量结果对照、一个短文本问答和一句合成音频（授权麦克风另行确认）。不跑200轮、不跑1000次、不同时满载三路。这个后续包尚未交付，不能把本次基础验收作为支付“全部项目功能通过”的唯一依据。若刷机委托只要求官方系统可启动，按对应范围验收即可。

闻到异味、供电反复掉线、异常发热、温度达到停止值、程序超时/报错时停止后续测试；不要靠复位/换DT强行通过。有无法关闭的板端进程时先保留串口日志再人工处置，不循环启动计算。

## 本次文件

- `quick_check.py`：真实信息采集、温度/内存门禁和可选CPU小样。
- `cpu_smoke_a53`：实际ARM64程序；`cpu_smoke.c`为对应源码。
- `run_check.ps1`：Windows连接/上传/运行/取回报告。
- `SHA256.json`：文件完整性清单；不是数字签名。
- `BUILD_STATUS.json`：PC测试/交叉编译状态，BOARD仍未测。
- `给刷机人员.md`：只发给刷机人员的刷机要求。

本包不包含固件、SD镜像、模型、许可证或密钥。给专业人士还需发送指定的两个刷机文件。
