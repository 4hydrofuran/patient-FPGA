# Hallmark 纸质评阅记录版

## 设计依据

使用者为通过7寸触屏进行模拟问诊与复盘的训练者。主分辨率为用户确认的1024×600横屏；用户选择“纸质病历：像教师评阅记录”。本次按 Hallmark 的单页 redesign 流程实施，结构为 Long Document，主题 Newsprint，复用现有本地中文字体和用户已有美术，不加载远程字体或新图片。

## 做了什么

- 页面由展示式大分数改为评阅记录：暖白纸面、中文衬线正文、较小的真实分数与少量批注红。
- 精简重复标题、黄色长提示条、内部后端/病例代码和冗余场景文案。规则演示身份与草案/待审核标记仍然清楚可见。
- 评阅意见、评分依据、待复核和问诊记录采用四个48px高的页签。支持左右键、Home、End及可见焦点；各页只显示当前内容。
- 评分依据仍可展开每项的原始问题，复核原因、问题原文和轮次状态均保留。总结只省略已在顶部显示的重复分数句，API原文未改写。
- 主任在评阅/查阅时切换已有立绘，背景成为陪伴阅读的诊室画面，主要空间让给记录正文。
- 横屏的总分、页签与“开始新问诊”按钮固定可见；正文独立滚动。问诊输入、发送/取消/结束操作固定底部；新问题跟随到最新记录，回看旧问题时保留滚动位置。

只修改现有 static/index.html、evaluation.css、tokens.css、console.js 的视觉与交互层，未改路由、模型适配、A02规则、评分数学、回执或持久化语义。原入口样式保留，新样式在原文件中追加覆盖；没有删除文件。修改前的四份源文件副本在 runtime/hallmark-before/，旧效果图在 docs/history/evaluation-before-hallmark.jpg。

## 验证与限制

软件回归结果见 redesign-test-results.xml；页面操作、长文字、页签/键盘、空问诊及响应式检查见 acceptance/paper-review-browser.json。对比度和源码身份见 VERIFICATION.json。

已检查1024×600、1024×520可用高度、1280×800，以及320/375/414/768宽度回退。横屏主要操作和页签均至少48 CSS像素高，文字未依赖动画或悬停显示。截图 paper-review-preview.jpg 为实际浏览器页面。

这些是电脑上的浏览器检查；实体触屏、板端字体、系统缩放和软键盘仍需在KV260环境验证。本次没有部署真实模型或修改SD卡。
