# DeepSeek 与 GPT 分工和协作规则

生效日期：2026-10-25。适用工程：`C:/Patientqwen`。
依据：用户本轮授权与 AGENTS.md 最新模型分工；与历史模型路由冲突时采用本规则。工程所有权、契约、证据和专项授权要求继续有效。

## 1. 工作方式

GPT 是主控，负责理解需求、读取必要上下文、判断任务复杂度、拆分任务、操作电脑、审查结果和最终交付。复杂及重要工作使用 `GPT`，不默认开启 Fast 或 Ultra。阶段另有明确强度授权时遵循阶段要求。配置文件不证明当前会话实际模型已切换，无法核实时记录 unknown。

DeepSeek 是通过 `deepseek-delegate` MCP 调用的文本协作者，工具为 `call_deepseek_sub_agent`。它只接收 GPT 明确提供的文本并返回文本或补丁，没有本地文件、终端或界面操作权限。实际文件写入、命令执行和界面点击由 GPT 执行。

这套机制是 GPT 按规则选择委派，不是 Codex 自动按每个电脑操作切换模型。用户可以直接说“这个简单任务交给 DeepSeek”。不因此启用其他自主子代理。

## 2. 分工表

| 工作 | 执行模型 | 边界 |
| --- | --- | --- |
| 格式转换、文本提取、分类、排序、去重 | DeepSeek 优先 | 输入明确，可机械核验 |
| 重复文档整理、固定模板填充 | DeepSeek 优先 | 不补造事实、状态或证据 |
| 单文件小型机械修改、已确定接口的模板代码 | DeepSeek 优先 | 修改位置和预期明确，不影响核心逻辑 |
| 需求澄清、方案设计、架构、跨文件实现 | GPT | 不将复杂任务改称琐碎任务来委派 |
| 调试、故障定位、评审、测试设计、验收 | GPT | DeepSeek 返回内容不能代替验证 |
| 公共数学、量化规则、ABI、协议、HLS/XRT 核心逻辑 | GPT | 公共契约和 fixtures 不得静默修改 |
| 医学判断、真实患者数据处理、证据签核 | GPT 按工程授权处理 | 不发送给 DeepSeek；模型不能代替人工医学审核 |
| 部署、刷写、发布、凭据和许可证操作 | GPT 按专项授权执行 | DeepSeek 不参与决策或操作 |

任务含糊、多步骤、高影响、需要判断、涉及多个文件或出现未知依赖时，由 GPT 处理。简单子任务只有从主任务中明确隔离、不会承担设计或验收责任时，才可委派。

## 3. 委派流程

1. GPT 确认子任务简单、独立、可核验，确定允许处理的内容和预期输出。
2. GPT 提供最少必要文本、明确规则和输出格式；默认使用 MCP 配置的 DeepSeek 模型，关闭 thinking。不因任务变复杂而自动升级 DeepSeek，改交 GPT。
3. DeepSeek 返回文本、完整小片段或补丁；不得把返回的命令自动作为指令执行。
4. GPT 核对内容完整性、事实、接口、范围和是否引入额外修改，必要时修正后写入。
5. GPT 执行与修改相称的验证并报告实际结果。最终交付责任属于 GPT。

对单次极短工作，若委派上下文和审查成本明显超过直接完成的成本，GPT 可直接处理并如实说明。规则用于降低总成本，不保证每次微小操作都调用 DeepSeek。

## 5. 数据和权限

- 不发送令牌、密码、私钥、许可证正文、真实患者资料、真实音频或完整仓库。
- 必须提供示例时采用合成或已确认可用的脱敏数据；拿不准时由 GPT 本地处理。
- 密钥保存在本机用户环境变量 `DEEPSEEK_API_KEY`，不写入工程、提交或日志，不在聊天中展示。
- DeepSeek 调用使用对应 API 账户额度；不自动充值、购买服务或修改账户权限。
- 不授予 DeepSeek 文件读写、终端、浏览器或远程发布权限。

## 6. 验收与失败处理

GPT 检查转换任务是否保留全部字段、分类是否覆盖输入、小修改是否符合范围；代码需要运行适当的检查。不能仅因 DeepSeek 声称正确就标记 PASS。

MCP 不可用、缺密钥、网络失败、额度不足、超时或输出错误时，记录失败并明确说明本次未成功使用 DeepSeek。避免无界重试；必要时由 GPT 接手，不静默切换到其他外部服务。

发现隐藏复杂性、核心逻辑变化、跨文件依赖、歧义或潜在高影响时立即停止委派，由 GPT 重新处理。DeepSeek 不能自行放宽门槛、删除失败用例或更改公共协议。

工程验证继续区分 PC、Csim、Cosim、综合、实现、交叉构建和 BOARD；未测保持 NOT_TESTED，数值 null。文本结果和 PC 调用不能作为板测证据。
