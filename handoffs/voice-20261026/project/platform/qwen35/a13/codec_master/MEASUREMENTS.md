# 待板卡释放后的验收清单（本轮不执行）

用户已确认外部5V接VIN、跳线5VIN、旧KV260 J2供电线断开、共地、信号仍3.3V。
这些是用户确认，不是仪表测量。模块不再从J2的3.3V预算取电；外部电源仍有其
额定电流和保护上限，不能称“无限电流”。实际静态/峰值电流、电压、板外时序均null。

| 项目／需要的工具 | 原因与待记录的结果 | 前置及边界 |
| --- | --- | --- |
| 板卡释放证明／当前系统只读状态 | 另一任务独立后检、正常恢复、无有效占用/租约/双锁；再核对boot、内核、PL/DT与原件hash | 仅收到后续明确调试指令后安排；不能以旧租约归档代替新鲜状态 |
| 电源及实际I/O电压／万用表 | 核实外5V、内部轨/上拉是否仍3.3V，确认无5V回灌J2或信号线；记录电源型号、额定电流、接线和静态电流 | 先断电安排测量；不把电流档并联VIN/GND；不要凭跳帽标签推断I/O实测电压 |
| 上电及受控状态峰值／合适的电流测量方案 | 普通万用表不能捕获瞬态；核对电源、模块、线缆额定值与测量误差，异常压降/发热即停 | 无需先购买工具；没有条件的项目保持NOT_TESTED，不能以低音量替代保护 |
| IIC电平与边沿／示波器 | 100kHz只是配置值；WM8960要求上升及下降均不超过300ns，还需核对SCL高低、起停、数据建立保持和ACK | 不擅改上拉。逻辑分析仪可解码但不能证明模拟边沿。功放/输出路径保持关闭 |
| 24MHz、BCLK、DACLRC／示波器或计数工具 | 确认24MHz原振荡器与codec PLL；目标48kHz、16位双声道槽、BCLK=32Fs≈1.536MHz；核对占空比、频差、唯一驱动 | 保留P1.10/P1.14未接；不外加MCLK、不拆晶振。只在已识别测试点测量 |
| LR/ADCDAT跨链及DACDAT时序／多通道示波器 | 芯片master时序表给LR/ADC相对BCLK下降沿传播上限10ns、DAC对上升沿setup/hold各10ns；加入线缆、板路、片内路径和误差 | 当前四拍额外等待和>100ns预算是有条件模型，不是实测或MTBF保证 |
| Linux驱动/声卡/DMA/IRQ与恢复／日志、数字测试 | 实际probe、codec PLL配置、每256帧/1024B包尾、DMA周期回调、欠载/溢出/失钟与停止恢复仍未测 | 当前模块永久EPERM且DT disabled，不能直接改status或删锁开流；需另版候选和评审 |
| 后续低音量TTS／另行受控音频窗口 | 确认声卡/采样转换后再检查可懂度、音量和峰值电流 | 不属于本轮。必须先完成前置，并由用户明确允许；本轮播放/录音均0 |

示波器地夹只接已确认的公共地。无源喇叭为BTL连接，喇叭任一端均不可当作地或
连接接地探头地夹；本轮不测喇叭输出。照片只用于辨认板本和安全测试点，不能代替
电流或时序测量。原始波形应带时间/电压刻度、带宽、探头与负载条件，不要求真实语音。

依据：[WM8960 Rev4.4，第14、16页](https://mm.digikey.com/Volume0/opasdata/d220001/medias/docus/307/WM8960.pdf)。
芯片表的测试条件和当前模块工作条件须在实测时一并核对。
