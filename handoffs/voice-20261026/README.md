## 接手后的最短路径

1. 先读[`project/docs/handoffs/A_A13_FAST_PREBOARD_COMPLETE_20261026.md`](project/docs/handoffs/A_A13_FAST_PREBOARD_COMPLETE_20261026.md)。
2. 解压板前包，只运行默认查看：`python3 -B /绝对新目录/a13-fast-preboard/runner.py`。
   输出应为`PLAN_ONLY_NOT_EXECUTED`，不会连接或操作板卡。
3. 板测另在明确的维护窗口执行：一次合并前检后，绑定新鲜boot/内核/日志、实际独占、
   供电和恢复出口。模板保持未授权，不能复用历史boot或旧待认证关机窗口。
4. 单次PL配置→音频DT/受限静音codec→全零短流与满流→正常停流。完成只得到
   `AUDIO_IDLE_RESERVED`，保留音频配置/维护所有权；不自动热回载、强卸载、清租约或重启。
5. 完成真实静音及恢复验收后，再安排模型文件推理和低音量输出；ASR录音另行验收。

无需重建SDK、重复已有RTL/CDC/STA或增加dummy DT板测。仅对实际后续修改做相关验证。
工具固定AMD2026.1；现包内核精确锁6.8.0-1036-xilinx，其他内核直接拒绝，不能强行加载。

供电按最近确认：模块外部5V接VIN、跳线5VIN、旧J2 3.3V供电断开、共地、六信号为3.3V。
保留24MHz晶振。此前报告的3.3V/100mA是历史状态；5V也不代表无限供电或已测电流。
